# OpenFleet brand assets

The logo is **Formation**: three chevrons flying together in cyan, magenta and yellow (top to bottom, the tri-colour order), a fleet moving as one.

| File                                     | Use                                                                     |
| ---------------------------------------- | ----------------------------------------------------------------------- |
| `logo-mark.svg`                          | The mark alone, transparent, for dark backgrounds                       |
| `logo-icon.svg`                          | The mark on a dark rounded square: favicons, avatars, light backgrounds |
| `logo-mark-512.png`, `logo-icon-512.png` | PNG versions of the two above                                           |
| `logo-horizontal-dark.png`               | Mark and cyan wordmark, for dark backgrounds                            |
| `logo-horizontal-light.png`              | Icon and ink wordmark, for light backgrounds                            |
| `social-preview.png`                     | GitHub social preview (1280×640)                                        |

The site uses `site/logo.svg`, `site/favicon.svg`, `site/apple-touch-icon.png` and `site/og.png` (1200×630 link preview).

Geometry (32-unit grid): chevrons from x 5 to 27 with the apex at x 16, tips at y 12, 19.5 and 27, apexes at y 5, 12.5 and 20, stroke 3.6 with round caps and joins. Colours: Luck Cyan `#48A6EE`, Luck Magenta `#EE5AD6`, Luck Yellow `#EDEB3C` on Arcade Ground `#0E0E10`; ink `#2B1E1B` for the light wordmark. The wordmark is Russo One in capitals. Don't recolour, reorder or rotate the chevrons, and keep the yellow one off white backgrounds (use the icon version there).
